# Fitness Intensity ML Pipeline

Machine learning pipeline for predicting workout intensity levels using supervised learning techniques and automated preprocessing workflows.

## Overview

This project demonstrates an end-to-end machine learning workflow including:

- Data preprocessing
- Feature engineering
- Model training
- Hyperparameter tuning
- Cross-validation
- Model evaluation
- Artifact generation

This repository showcases a modular machine learning workflow focused on preprocessing, training, evaluation, and model optimization using Python and scikit-learn.

---

## Stack

- Python
- scikit-learn
- pandas
- NumPy
- joblib
